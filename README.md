# QRScanner

macOS 14+ 原生菜单栏二维码扫描器。Swift + AppKit + SwiftUI，ScreenCaptureKit 捕获画面、Apple Vision 本地识别，无第三方依赖。

## 启动

双击根目录 **Launch.command**。脚本使用已安装的 Xcode / Swift 编译，并打开 `build/QRScanner.app`。以后也可直接打开该应用。当前构建针对本机架构，尚未制作通用分发包或 Apple 公证版本。

首次左键扫描时，在系统设置 → 隐私与安全性 → 屏幕与系统音频录制中允许 QRScanner。若系统要求重启，退出应用后重新打开。

## 操作

- **左键菜单栏二维码图标**：进入扫描模式，鼠标所在窗口高亮。**单击**识别该窗口；**拖动超过 5pt** 改为矩形框选。Esc 或右键取消。
- 单个 HTTP / HTTPS 链接默认交给系统默认浏览器打开，可在设置关闭自动打开。
- 非网页内容显示结果，可复制；多个二维码显示列表供选择。
- **右键菜单栏图标**：开机启动、自动打开链接、扫描完成通知、设置和退出。
- 设置窗口关闭后仍在菜单栏运行。首次发送通知会请求系统授权；被拒绝不影响扫描。

扫描显示冻结画面，避免选区与实际识别内容因窗口移动而不同。矩形框选限于起始显示器；跨屏窗口选择会合成各屏可见部分。未指向普通窗口时选择整个显示器。

## 隐私与权限

截图仅在内存中处理，扫描结束后释放；不写入截图、二维码历史或遥测。通知不包含完整二维码内容。只允许无嵌入用户名/密码的 HTTP(S) 网页链接，其他数据不执行。开启自动打开后，识别到的网页会产生正常浏览器访问。

屏幕录制权限允许应用访问的范围大于最终选区；应用仅在用户启动扫描时捕获。开机启动通过系统登录项管理，可随时在设置关闭。通知是否显示受系统权限与专注模式影响。

## 开发

```sh
./scripts/build.sh
./scripts/test.sh
```

用 Xcode 打开 `Package.swift` 可浏览和调试 Swift Package；直接启动未包装的可执行文件不适合验证系统通知或权限，实测请使用 `.app`。脚本设置项目内模块缓存以兼容受限环境。

构建先在临时目录完成签名；二进制和配置未变时保留现有应用，避免无意义地更新权限身份。代码变化且 QRScanner 正在运行时，构建会停止部署，请先在菜单栏右键退出再重试。不要在运行中手动覆盖 `.app`。

默认使用 ad-hoc 签名，代码更新后 macOS 可能要求重新授权。需要跨版本稳定授权时，安装 Apple Development / Developer ID 签名证书，并设置 `QRSCANNER_SIGN_IDENTITY` 为证书名称或指纹后构建；脚本不会自动创建证书或修改钥匙串。

若系统设置已有条目但仍反复提示：先完全退出 QRScanner；确认以后仅从本项目 `build/QRScanner.app` 启动。重新打开后再试；若仍失败，在系统设置中移除旧 QRScanner 条目，用当前应用发起扫描并重新授权，按系统提示退出重开。权限操作由用户手动完成；不需要重置其他应用的权限。

规范见 `AGENTS.md`；架构见 `docs/ARCHITECTURE.md`；真实验证状态与限制见 `DEVELOPMENT_LOG.md`。
